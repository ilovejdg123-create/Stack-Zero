# STACK ZERO V31

이번 버전은 V30의 기능을 유지하면서 다음을 수정했습니다

- 테스트 모드 공부 STACK: -50 / +50
- 레벨 바로 아래 작은 범위/재질 표기: `STACK 0~100 · 흙` 형식
- 현재 레벨 카드 바로 아래에 카구야 코치 배치
- 빈 보상 영역을 숨기지 않고 항상 `🎁 보상 받기`와 `🎒 보유 보상` 영역 표시
- QUEST 달성 → 보상 받기 대기 → 받기 → 보유 보상 → 사용 흐름 유지
- 레벨별 테마에 재질별 애니메이션/광택 효과 추가
- 다이아: 흰색 결정 반짝임
- 파도: 진한 파란색 + 흰색 물결/스파클
- 번개: 번개 플래시/볼트
- 불꽃: 불씨/열기 펄스
- 전설: 왕실 스파클
- 초월자: 별/성운 효과
- Gemini 호출 경로를 `/api/coach-v31`로 분리해 이전 정적/구버전 응답과 섞이지 않게 함
- Gemini 실패 시 테스트 모드에서 연결 실패가 명확히 표시되도록 변경

## 배포

GitHub Pages는 정적 파일만 실행하므로 `api/coach-v31.js`는 Vercel Function으로 배포되어야 합니다
Vercel 프로젝트가 이 저장소와 연결되어 있다면 `api/coach-v31.js`가 포함된 커밋을 배포하세요
Vercel 환경변수에는 `GEMINI_API_KEY`가 필요합니다

프론트엔드는 `https://stack-zero-three.vercel.app/api/coach-v31`을 호출합니다
