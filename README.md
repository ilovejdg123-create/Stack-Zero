# STACK ZERO V36.7

## 핵심 변경

### 1) 카구야 대사 시스템 전면 재설계
- 고정 호칭 승급표 삭제
- 기본적으로 이름/호칭 없이 자연스럽게 대화
- 호칭을 매 대사 첫머리에 붙이는 패턴 제거
- 최근 대사 20개를 Gemini에 전달해 문장 구조·핵심 단어·어미 반복을 강하게 억제
- 매 호출마다 표현 방향과 문장 리듬을 바꿔 같은 느낌의 대사가 반복되지 않도록 개선
- 칭찬만 반복하지 않고 관찰/장난/도발/짧은 인정/당황/걱정을 상황에 따라 섞음
- 문자 느낌·특수문자·이모지는 대부분 사용하지 않고 감정이 올라온 순간에만 드물게 사용
- 로컬 fallback 대사도 호칭 의존을 제거하고 상황별 문구 수를 크게 확장
- Gemini 생성 다양성을 위해 temperature/topP 조정

### 2) 날짜 선택형 달력 일정
- 기존 월~일 반복 일정 UI 제거
- `이번달 일정` 카드에 실제 월간 달력 표시
- 달력에서 날짜를 직접 누른 뒤 `시간 + 할 일` 입력
- 날짜별 여러 일정 저장 가능
- 일정이 있는 날짜에는 작은 점 표시
- 선택한 날짜 아래에서 일정 완료/취소/삭제 가능
- 이전/다음 달 이동 가능
- 일정은 localStorage의 `calendarSchedule`에 날짜별 저장
- 구형 V36.6 반복 일정이 있으면 처음 한 번 현재 날짜 일정 구조로 자동 변환
- Gemini에 오늘 일정 + 오늘부터 약 한 달의 날짜별 일정 전달

### 3) 기존 V36.6 기능 유지
- 공부 STACK 변경 시 카구야 기본 이미지는 항상 STACK 단계 사진 유지
- 운동/수면/QUEST/일정 등 이벤트 mood 이미지는 잠깐 표시 후 STACK 이미지로 복귀
- 4~10 STACK 점진 파티클
- 11~14 STACK 카구야 확대 + 하트 연출
- 다이아/파도/불/전설/초월자 고급 테마 유지
- Gemini 무한 입력중 방지 타임아웃/fallback 유지
- QUEST / 보상함 / 기록지 / 인증사진 / 테스트 ±50 유지

## 배포

### Netlify
1. 이 폴더 내용 전체를 GitHub 저장소에 업로드
2. Netlify에서 GitHub 저장소 연결
3. Environment Variables에 `GEMINI_API_KEY` 저장
4. 새 Production deploy 실행
5. `/api/coach?probe=1`에서 `keyConfigured:true` 확인

### Vercel
기존 방식대로 `GEMINI_API_KEY` 환경변수를 유지하면 됩니다

선택 환경 변수:
- `GEMINI_MODEL` 기본값 `gemini-3.6-flash`
- `GEMINI_FAST_MODEL` 기본값 `gemini-3.5-flash-lite`
